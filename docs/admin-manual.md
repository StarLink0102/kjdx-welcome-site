# 后台操作手册 · 河南科技大学新生迎新系统

后台地址：`/admin`（独立登录页）。后台为**可视化本地编辑器**，所有修改即时在本会话预览，确认无误后「导出配置」替换 `site-data.json` 即可生效。

## 一、管理员登录
1. 打开 `/admin`，输入账号 `admin`、密码 `admin888`；
2. 输入图形验证码（看不清可点击验证码刷新）；
3. **首次登录会强制修改初始密码**（至少 6 位），修改后请记得「导出配置」保存；
4. 忘记密码：联系技术管理员，或在 `site-data.json` 的 `siteConfig.adminPassword` 直接修改后重新导入。

## 二、左侧菜单
- **数据看板**：站点内容统计与访问趋势（演示数据，纯静态无服务端统计）。
- **轮播图管理**：增删轮播、拖拽排序、单张上下线、编辑文字浮层与跳转、全局播放设置。
- **内容管理**：选择板块 → 管理内容块（富文本/表格/图片/卡片/问答/步骤），支持拖拽排序、显隐、富文本编辑与实时预览。
- **全局设置**：站点名称/Logo/校徽、报到倒计时、客服微信、页脚与备案、免责语、**全站密码锁开关与主/备用密码**、禁止右键复制。
- **AI 配置**：人设话术、温度、回答长度、上下文轮数；**广告关键词与文案**（命中自动追加）；兜底话术与微信号；分板块/全局知识库维护。
- **代理管理**：开通/禁用代理、权限勾选、专属密码/微信/广告/轮播覆盖、生成专属推广链接。

## 三、内容编辑（通用）
- 每个列表项右侧有「上移/下移、编辑、删除」；
- 富文本编辑器支持加粗、标题、列表、链接、图片，并可一键「预览」；
- 表格可增删行列；卡片/问答/步骤可增删条目；
- 修改后点击「保存」，本会话前台即时同步。

## 四、代理账号开通流程
1. 进入「代理管理」→「新增代理」；
2. 填写代理名称、联系备注、登录账号与初始密码；
3. 勾选权限范围（自定义密码 / 广告 / 微信 / 轮播）；
4. 保存后系统生成「专属推广链接」`?channel=代理ID`，点击「复制推广链接」发送给代理；
5. 在代理详情中维护其专属覆盖（密码/微信/广告/欢迎语/轮播）；可启用/禁用、重置密码。
6. 代理用本人账号登录 `/admin` 后，仅能编辑授权范围内的专属配置，不影响主站与其他代理。

## 五、AI 配置方法
- **知识库**：在「AI 配置 → 知识库」选择板块或全局，添加「问题 / 标准回答 / 关键词」；对应板块唤起 AI 时优先调用该板块知识库。
- **广告植入**：在「广告触发配置」添加关键词（如 校园卡、电话卡）与对应 HTML 文案，命中关键词的回答末尾自动追加。
- **兜底话术**：AI 无法匹配时输出兜底文案并引导添加客服微信（可替换渠道专属微信号）。

## 六、保存与发布
- 左上角「导出配置」下载 `site-data.json`；
- 「重置本地改动」可清除本会话的本地覆盖，恢复到文件原始内容；
- 将导出的 `site-data.json` 替换 `frontend/public/site-data.json` 并重新构建部署，即全网生效。

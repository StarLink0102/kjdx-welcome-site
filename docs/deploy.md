# 部署文档 · 河南科技大学新生迎新网站系统

本系统为**纯静态前端站点**，不依赖任何后端服务、云数据库或云存储，部署零云服务费用。

## 一、环境准备
- Node.js 18+ 与 pnpm（或 npm）
- 任意静态文件托管服务：云开发静态托管、对象存储 + CDN、Nginx、GitHub Pages、Vercel、Netlify 等均可

## 二、本地构建
```bash
cd frontend
pnpm install
pnpm build
```
构建产物位于 `frontend/dist/`，即整站静态资源。

## 三、部署上线
将 `frontend/dist/` 目录下的全部文件上传到托管空间根目录即可。

> SPA 路由说明：本站使用前端路由（`/` 与 `/admin`）。若使用 Nginx / 对象存储等，请配置「所有路径回退到 `index.html`」（`try_files $uri /index.html`），否则刷新 `/admin` 会 404。Vercel / Netlify 一般默认已支持。

## 四、内容配置（无需改代码）
全部内容、轮播、板块、AI 知识库、代理信息均集中在 **`frontend/public/site-data.json`**：
1. 进入后台 `/admin`，登录后在各模块编辑内容；
2. 点击左上角「导出配置」，下载 `site-data.json`；
3. 用下载的文件**替换** `frontend/public/site-data.json`，重新执行 `pnpm build` 并重新部署。

（后台编辑也会在本会话浏览器内即时预览，便于先确认效果。）

## 七、安全说明（纯静态模式的固有边界）
- 密码校验在前端完成，密码存放于随站点分发的 `site-data.json` 中，属演示级保护；正式对外建议配合「隐藏真实访问密码 + 仅向授权对象发放」的方式使用。
- 无服务端，故无法跨用户统计访问量/对话量（后台看板为演示数据），也无法做服务端限流与 IP 封禁。
- 已落实：富文本 XSS 过滤、密码错误次数锁定、DOM 遮挡防绕过、图片懒加载与失败占位、AI 兜底与降级。
